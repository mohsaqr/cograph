# Built-in Themes

Pre-defined themes for network visualization.

## Value

A `CographTheme` object.

## Examples

``` r
theme_cograph_classic()
#> CographTheme: classic 
#>   Background: white 
#>   Node fill: #4A90D9 
#>   Node border: #2C5AA0 
#>   Edge color: gray50 
#>   Edge positive: #2E7D32 
#>   Edge negative: #C62828 
theme_cograph_dark()
#> CographTheme: dark 
#>   Background: #1a1a2e 
#>   Node fill: #e94560 
#>   Node border: #ff6b6b 
#>   Edge color: gray60 
#>   Edge positive: #4ecca3 
#>   Edge negative: #fc5185 
```
