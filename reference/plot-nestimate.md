# Nestimate Plotting Methods

Plot methods for Nestimate network objects, including `netobject`,
`boot_glasso`, `wtna_mixed`, `netobject_group`, `netobject_ml`,
`net_bootstrap_group`, and `net_stability`. No Nestimate import is
needed — dispatch is via
[`inherits()`](https://rdrr.io/r/base/class.html) class-name checking
only.
