# Centrality Zoo coverage

What the [Centrality Zoo comparison](https://centralityzoo.github.io/comparison/)
(Shvydun 2025, *Zoo of Centralities*, arXiv:2511.05122) says about cograph's
`centrality()` surface. Generated by `docs/zoo/zoo_coverage.py` from the
site's `correlation.json` (gzipped copy in `docs/zoo/`). Regenerate after adding
measures; edit the `COVERED` map in the script, not this file.

## Source

- Matrix of average **Kendall rank correlation** between node rankings,
  349 measures, computed on 648 empirical networks from the Index of
  Complex Networks (ICON). The encyclopedia assumes undirected, unweighted,
  loop-free graphs, so redundancy on a directed weighted transition matrix
  may differ.
- Off-diagonal tau: min 0.00, median 0.67, mean 0.63, max 1.00.
- The Zoo's own code is unreleased (its Code page says so), so nothing here
  is validated against Zoo output. cograph validates each measure against
  reference packages, published worked examples, or brute-force igraph.

`tau` below is the **maximum** Kendall correlation between the Zoo measure and
any measure cograph already computes; `nearest` names that cograph twin (Zoo
label). A tau of 0.99 or more means the two rank nodes identically on
essentially every one of the 648 networks, so adding the measure buys nothing.

information dimensionality, modularity vitality and neighborhood

ranked list: the three Shapley games, access and hide information, rumor

betweenness), the s-shell index, DegreeDiscountIC, SingleDiscount and

Deliberately skipped:

- **Hybrid (Pozzi)**: tau 0.00 with all 348 partners: looks like a broken run, not a measure
- **Physarum / K-shell Physarum centrality**: iterative flow solver, heavy
- **Absorbing Random-Walk (ARW)**: set-function greedy, heavy
- **LRIC family, SRIC, Interdependence**: author's own long-range-influence measures; no closed form
- **Node information dimension (NID)**: box scheme in the encyclopedia is ambiguous; original paper paywalled
- **Game centrality (GC), Algebraic centrality, Community centrality**: definition not pinned
