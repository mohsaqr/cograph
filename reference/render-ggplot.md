# ggplot2 Conversion

[`sn_ggplot()`](https://sonsoles.me/cograph/reference/sn_ggplot.md)
converts a network to a ggplot object.

## Value

[`sn_ggplot()`](https://sonsoles.me/cograph/reference/sn_ggplot.md)
returns a ggplot object representing the network.

## Examples

``` r
sn_ggplot(regulation_net)
```
